# idea-01：分割质量 → 位姿误差 的敏感性曲线与不确定性传播

> 状态：🟡 待验证 ｜ 建立：2026-10-03
> 来源缺口：[05 研究缺口清单](../00-总表整理/05_研究缺口清单.md) 缺口 ②（分割-位姿误差传播未建模）+ ⑤（分割质量与位姿误差的定量关联）
> 来源论文：[MR6D](../01-笔记/MR6D-Benchmarking%206D%20Pose%20Estimation%20for%20Mobile%20Robots.md)

## 一句话

把「2D 分割是 unseen pipeline 的瓶颈」从**排序性观察**升级为**定量关系**：建立 分割质量 → 位姿误差 的敏感性曲线，并检验能否用分割不确定性预测位姿误差。

## 为什么现在做

- MR6D 明确指出：全 unseen pipeline 中 **2D 分割质量是主要瓶颈**，但**没有给出定量关系**。
- 换句话说，论文把「这里是瓶颈」标出来了，**尺子还没人做**。做尺子的成本远低于做方法。
- 从科研起步的角度：这是一个**不需要训练任何模型**就能产出结果的题目，一周内可完成最小版本。

## 三条准入检查（缺一条就不做）

| 检查项 | 内容 |
| --- | --- |
| **能说出反例** | 如果敏感性曲线是**平的**（mask IoU 从 0.9 降到 0.5，位姿 AR 几乎不变），说明 2D 分割并非主要瓶颈，MR6D 的结论就是场景特定的、甚至不成立 |
| **最小验证实验** | 取 LM-O / 一个 MR6D 子集，用 GT mask 做基准；人为退化 mask（膨胀 / 腐蚀 / 随机擦除 / 用 SAM 过分割结果替换），每种退化程度跑一次官方评测，画「退化程度 — 位姿指标」曲线 |
| **有对照** | 对照 = GT mask 的上界；指标 = BOP 的 AR / ADD-S（与 BOP、MR6D 直接可比）；数据集 = LM-O（已验证可下载）或 MR6D 子集 |

## 可能的延伸（做完最小版本再考虑）

1. **不确定性传播**：把分割模型输出的像素级置信度，经 pipeline 传到位姿输出，检验「位姿不确定性」能否被**校准**（预测的置信区间是否覆盖真值）。
2. **反哺分割**：如果曲线在某段特别陡，说明该区间的 mask 需要重点优化 → 分割模型可以用「下游位姿误差」当奖励信号，而不是用 IoU。
3. **和阶段六合流**：Conformal Keypoint / UA-Pose 这条不确定性线正好在阶段六，做完最小版本后去读，会有共鸣。

## 风险与待确认

- ⚠️ MR6D 数据集**是否公开**、4 个子集构成如何，笔记未记录 → 先用 LM-O 推进，不阻塞。
- ⚠️ 「CTL masks」是用什么分割模型产出的，笔记未展开 → 若能确认，退化实验的「最真实退化方式」就有了参照。
- ⚠️ FoundationPose 环境能不能在本机跑通（有无 GPU）→ 这决定最小版本用不用得上真实 pipeline；退一步，可以只用官方 toolkit 做「mask 退化 → 指标」的纯评测实验。
