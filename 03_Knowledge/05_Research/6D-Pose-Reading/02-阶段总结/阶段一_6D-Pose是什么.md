## 一句话

**6D Pose Estimation = 给定一张（或一组）图像，估计某个已知刚体实例相对相机坐标系的 3D 平移 + 3D 旋转。**

「6D」= 3 个平移 + 3 个旋转，合起来是一个 SE(3) 上的位姿。

## 二、任务定义（从 BOP 拿到的口径）

BOP 把任务定义成一个二元组 **(I, o)**：

- **I** = 输入观测（在这个阶段的论文里是 RGB-D）
- **o** = 目标物体（已知的刚体实例，通常配一个 **texture-mapped 3D object model**，即 3D mesh + 表面纹理）

需要强调的两点，很容易读错：

1. **"已知物体"** 是这个阶段的核心前提。阶段五（Novel Object）才是把这些前提一条条拆掉的地方。
2. **texture-mapped 3D object model** 的用途是：渲染训练数据、提取特征、建立 2D-3D 对应、计算 ADD。没有它很多方法直接跑不起来。

## 三、输入谱系与前提矩阵

| 前提 | 本阶段（BOP 系） | 后面哪一阶段会拆掉 |
| --- | --- | --- |
| 输入模态 | RGB-D | 阶段二会讲纯 RGB 路线（PVNet 等）；阶段六有纯视觉 + 基础模型 |
| 是否需要 CAD / 3D 模型 | **需要**（texture-mapped 3D model） | 阶段四（category-level）、阶段五（CAD-free：OnePose / BundleSDF） |
| 物体是否训练时见过 | **见过**（实例级） | 阶段四（类别级）、阶段五（novel object） |
| 视角 | 固定（机械臂向下） | [MR6D](../01-笔记/MR6D-Benchmarking%206D%20Pose%20Estimation%20for%20Mobile%20Robots.md) 换成移动机器人多样视角 |

> **这张矩阵是阶段一到阶段六的路线图**：每往下一阶段走，就是拆掉上表的一行前提。

## 四、输出与歧义

- 常规输出：**R, t**（一个确定位姿）
- 遇到**位姿歧义**（pose ambiguities，来自 9.25 术语卡）：对称物体、无纹理、重复纹理会让多个位姿产生相似观测 → 更合理的输出是**位姿分布或多假设**，这正是阶段六 Corr2Distrib / SymCode 那批论文在做的事

## 五、评测体系（本阶段最重要的产出）

```
数据集  →  指标  →  协议  →  榜单
```

- **数据集**：BOP 统一了 8 个（LM / LM-O、IC-MI / IC-BIN、T-LESS、RU-APC、TUD-L、TYO-L）
- **指标**：ADD / ADD-S（实例级基础）、**VSD**（BOP 提出，替代 eADD / eADI 处理位姿歧义）、AR（平均召回，用于跨数据集给单值结论）
- **为什么需要统一**：不统一就「无法公平比较」——这是 BOP 存在的唯一理由
- 细节见 [03 数据集与指标表](../00-总表整理/03_数据集与指标表.md)

## 六、方法族（阶段一的分类学）

| 方法族 | 代表（BOP 测评中出现） | 一句话 |
| --- | --- | --- |
| 学习型（直接回归 / 分类） | Brachmann-16 | 网络直接输出位姿或位姿假设 |
| 模板匹配 | 模板类方法 | 拿渲染模板和观测比对 |
| **point-pair features（PPF）** | **Vidal-18、Drost-10** | 用一对 3D 点 + 法线构造几何描述子，匹配模型与场景点对，投票生成位姿假设 |
| 3D 局部特征 | Buch-17-ppfh | 匹配 3D 局部特征描述子 |

**本阶段实测排序（BOP 平均 recall）**：PPF（74.6%）> 3D 局部特征（54.0%）≈ 学习型（55.4%）。
⚠️ 注意这个排序的时间限定：**只为 2018 年以前的方法集合成立**（见 BOP 笔记批判节）。

> **补（2026-10-14 新读 PoseCNN）**：学习型这一支内部还要再分——BOP 表里的 Brachmann-16 是**直接回归 / 分类**，而 [PoseCNN](../01-笔记/PoseCNN-A%20Convolutional%20Neural%20Network%20for%206D%20Object%20Pose%20Estimation%20in%20Cluttered%20Scenes.md) 是**学习特征 + 几何投票**（像素语义标注 → 中心投票 → 四元数回归）。同样叫「学习型」，泛化与遮挡表现差别很大，横向对比时不能混成一格。

## 七、两条 pipeline（本阶段最实用的一个区分）

| | model-based / 评测 pipeline | unseen pipeline |
| --- | --- | --- |
| 出现在 | BOP | [MR6D](../01-笔记/MR6D-Benchmarking%206D%20Pose%20Estimation%20for%20Mobile%20Robots.md) |
| 流程 | 拿到 GT 或良好 mask → 匹配 / 回归 → 位姿 | 分割 → 识别 → 估计位姿，**没有对象特定训练** |
| 典型组合 | BOP 的 15 种方法 | CTL mask + FoundationPose |
| 瓶颈 | 遮挡、光照 | **2D 分割质量** |

> **这张对比表是阶段一给我最有用的东西**：它把「方法本身好不好」和「上游环节好不好」分开了。MR6D 的结论「pipeline 表现不佳」其实很大一部分是**分割的锅**，不是位姿网络的锅。

## 八、开放问题（BOP 实验直接给出的）

1. **遮挡**——所有方法在 LM 上至少比 LM-O 好 30%
2. **变化光照**——依赖合成 RGB 训练的方法脆弱，只用深度的方法更鲁棒
3. **对称性与物体相似性**——BOP 明确列为开放问题
