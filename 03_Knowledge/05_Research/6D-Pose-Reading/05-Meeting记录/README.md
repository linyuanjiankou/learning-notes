# 05-Meeting记录

每次 meeting 的内容留档，按日期编号，一次会议一个子文件夹。

## 目录结构

```
05-Meeting记录/
├── README.md                 # 本文件：命名约定 + 台账
├── 01_2026-10-11/
│   ├── 个人Meeting.md         # 会议文档
│   ├── 个人Meeting.pptx       # 配套 PPT
│   └── _生成PPT.py            # PPT 生成脚本（重跑可覆盖同名 pptx）
└── 02_YYYY-MM-DD/            # 下次会议
```

## 命名约定

- 子文件夹：`NN_YYYY-MM-DD`，`NN` 从 `01` 起按日期递增。
- 会议文档：`个人Meeting.md` / `项目Meeting_<项目名>.md`。
- 配套 PPT 与脚本与文档同目录，文件名固定 `个人Meeting.pptx` / `_生成PPT.py`。

## 会议文档结构（对齐《如何高效 Meeting》模版）

| 节 | 内容 |
| --- | --- |
| 1 | Review 大方向与定位 |
| 2 | 上次 meeting 的结论与 Todo（首次会议为「本次要对齐的点」） |
| 3 | 自上次以来的进展（三句话以内） |
| 4 | 想讨论的问题 / 观察 |
| 5 | 最近读的论文 + 一句话总结 |
| 6 | 后续 Todo 与时间安排 |
| 7 | 需要帮助 / 资源确认 |
| 8 | 本次结论与 Todo（会后填写） |
