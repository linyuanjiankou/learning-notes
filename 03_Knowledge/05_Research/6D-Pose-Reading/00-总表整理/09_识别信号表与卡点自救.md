# 09 识别信号表与卡点自救

> 来源：papers-notebook 论文阅读教练的**核心资产**——识别信号表 + 卡点自救流程。
> 右侧「对应动作」已按你已有的工作习惯（`入门/笔记/论文阅读方法以及AI辅助阅读.md`、`06_整理归档指南.md`）落地成 6D Pose 场景的具体动作，不是通用套话。

## 一、识别信号表

| 你现在的感受 / 场景 | 该用的方法 | 具体动作 |
| --- | --- | --- |
| 不知读哪篇 | 先读高引综述 / 基准定边界 | 用 [00_阅读看板](00_阅读看板.md) 的六阶段梯度，按 P0 → P1 → P2 顺序走，不要自己另开一条线 |
| 读不进全文 | 第1遍只读标题 / 摘要 / 图 | 泛读只看 5 个地方：Title → Abstract → Introduction 开头 → **Figure 1** → Conclusion。30 分钟收工 |
| 术语发怵 | 只问「**在本文中**它解决什么」 | 不要问「什么是 pipeline」，要问「在这篇论文里 pipeline 指哪几步」。9.25 / 9.26 的术语卡就是这个形态 |
| 公式发怵 | 先找「优化目标 + 符号表」 | 把公式读成一句话：**它在优化什么目标、哪些量是已知的、哪些是要求解的**。读不出目标就先跳过，记进 Unknown List |
| 看不出创新 | 对比 related work 的差异点 | 按 [07 模板](07_单篇结构化笔记模板.md) 第 3 问回答：**以前怎么做 → 这篇怎么改**。答不上来说明还没读懂 |
| 实验看不懂 | 盯「因变量 / 基线 / 消融」 | 每个数字都必须能补全「在 XX 数据集、XX 指标、与 XX 对比下，提升 XX」。补不全的数字不要写进笔记 |
| 记不住 | 用卡片记「问题 — 方法 — 局限」 | 你的术语卡已经是这个形态，下一步是**归并成统一词表**（目前 9 条散在两个工作记录里） |
| 不会批判 | 问「假设成立吗 / 数据够吗」 | 每篇笔记必须有「批判与待验证」小节，至少 2 条。这是 [00_阅读看板](00_阅读看板.md) 的铁律之二 |
| 想跟进 | 顺引用链向前 / 向后溯 | References（往前） + Cited by（往后）。9.22 计划的 Step 6 |
| **分不清论文类型** | 先判定：它是**方法论文**还是**基准/数据集论文**？ | 这是你这次读 BOP、MR6D 暴露出来的信号——两篇都是 benchmark，读完**不会**给你一条方法路线。所以阶段二必须补 PVNet 这一批 |
| **结论记成了作者的方法很强** | 检查主语 | BOP 里的 74.6% 是 **Vidal-18** 的成绩，不是 BOP 自己的。benchmark 论文里的差距是**被评测方法之间**的差距 |
| **一读就想查资料** | 建 Unknown List，按天统一解决 | 看到 attention / SE(3) / ARAP 先记下继续往下读，当天结束再统一查。避免「查三小时、忘记论文」 |

## 二、卡点自救四步

| 步骤 | 什么时候用 | 在 6D Pose 阅读里怎么做 |
| --- | --- | --- |
| **1 降级** | 整篇读不进、越读越烦 | 退回到**第 1 遍略读**：只看 Figure 1 和结论，能说出「输入是什么、输出是什么」就算这一轮达标。不要硬啃 Method |
| **2 提示分层** | 卡在公式 / 符号 | 按「**符号 → 假设 → 目标 → 推导**」拆成四层，逐层问自己懂不懂。通常卡点在第 2 层（假设）而不是第 4 层（推导） |
| **3 重做** | 觉得「好像懂了」但讲不出来 | 挑核心实验**自己跑最小版本**验证。对 benchmark 论文，就是跑通评测流程和指标计算——见 [00_复现计划](../03-代码复现/00_复现计划.md) |
| **4 登记** | 每读一篇结束时 | 产出一张笔记卡（贡献 + 漏洞 + 可复用点），并回填 [04 问题线索表](04_问题线索表.md)。**不登记 = 没读过** |

## 三、当前最该防的一个坑

你现在 2 篇笔记都是 benchmark 论文，**很容易形成「6D Pose 就是比来比去」的错误印象**。实际上 BOP/MR6D 只给了你**赛道和尺子**，还没给你**跑法**。

所以阶段二的 P0 四篇（PVNet / CDPN / DPOD / Pix2Pose）是本阶段优先级最高的动作——它们才回答「一个位姿到底是怎么被算出来的」。
