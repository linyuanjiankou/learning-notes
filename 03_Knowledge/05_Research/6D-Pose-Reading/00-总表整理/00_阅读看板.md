## 一、过程验收：一篇论文怎样才算「读过」

### 五步阅读链（依赖顺序，不可跳级）

| 步骤 | 动作 | 验收标准（达不到就是没读完） | 本系统里的落点 |
| --- | --- | --- | --- |
| 1 选题 | 说明为什么要读这篇 | 能用一句话说清「为啥读这篇」 | 本看板第二节的优先级栏 |
| 2 三遍读法 | 略读 → 精读 → 复盘 | 第1遍能写摘要，第3遍能画出脉络 | 笔记里的「三遍读法进度」节 |
| 3 拆解结构 | 动机 / 方法 / 实验 / 局限 | 能用模板填出论文骨架 | [07_单篇结构化笔记模板](07_单篇结构化笔记模板.md) |
| 4 公式与复现 | 对齐符号 / 跑最小实验 | 复现出核心的一张图或一张表 | [00_复现计划](../03-代码复现/00_复现计划.md) |
| 5 输出笔记 | 笔记卡 + 自己的批判 | 能向他人讲清这篇的贡献与漏洞 | [00_笔记索引](../01-笔记/00_笔记索引.md) |

### 两条铁律

1. **不写笔记的不算「读过」。** PDF 存下来不等于读了，只有笔记卡算登记。
2. **笔记必须含自己的批判。** 只抄作者结论的笔记 = 0 分；每篇至少 2 条自己的质疑 / 待验证项。

### 阶段四的特殊说明（针对你的选题）

BOP、MR6D 都是 **benchmark 论文，不是方法论文**，所以第 4 步的「复现」目标不是网络，而是**评测流程与指标口径**。这反而是当前阶段的低成本入口 —— 见 [00_复现计划](../03-代码复现/00_复现计划.md)。

### ⚠️ 2026-10-26 优先级重排说明（方向意见落地）

2026-10-14 定下的方向是：**重心转向近 1–2 年论文 + 找一篇源码读懂 metrics，不要求复现网络**。据此把 §二 的优先级重排成三档，**论文池本身不变（仍 46 篇）**，只改读数顺序：

| 档位 | 判定规则 | 篇数 | 含义 |
| --- | --- | --- | --- |
| **P0** | 年份 ≥ 2024 **且**（原 P0 **或** 阶段五/六的 P1） | **9**（全部未读） | 当前必读。集中在 novel object / open-vocabulary / foundation + 1 篇 2026 综述 |
| **P1** | 年份 ≥ 2024，但不满足 P0 条件 | **15** | 近期补充，P0 之后按兴趣挑（含已读的 MR6D） |
| **P2** | 年份 ≤ 2023 | **22** | **按需查阅**，不再按序通读。卡在哪条线就回去查对应那篇 |

三条配套规则：

1. **经典链降级不等于不读。** PVNet / CDPN / DPOD / Pix2Pose 这四篇原 P0，现是 P2 —— 它们是「位姿到底怎么被算出来」的来路。做法改为：**遇到不懂的机制时定向回查**，不再逐篇出全笔记。这也是待办 T2 的落地。
2. **判定只看年份与阶段归属，不看内容。** 因为本轮重排没有读原文，**不替任何一篇新论文断言它做了什么**；它挂哪条缺口，等读完在 [04 问题线索表](04_问题线索表.md) 里补。
3. **已读论文的优先级栏保留重排后的值**，仅供回看口径参考，不代表要重读。

## 四、metrics 源码线（待办 T8 的落地方式）

方向意见的原话是「**找一篇论文的源码，对着 metrics 清单读懂**」，不是复现网络。所以这条线的产出不是模型，而是**一张自己能讲清的指标对照表**。

### 清单（8 项，来自 [11_问题与待办](11_问题与待办.md) T8）

对每个指标要能回答三件事，缺一件就是没懂：

1. **定义**：公式在源码哪个函数里？
2. **口径**：阈值法（ADD < 0.1d、VSD < 0.2）还是 AUC（窗口积分）还是 <2cm？换口径数字会变几倍？
3. **入口**：输入是什么形状（位姿矩阵 / 点云 / mask / 深度图），输出是什么。

### 代码落点（已确认的只有两处）

| 指标 | 去哪读 | 状态 |
| --- | --- | --- |
| ADD / ADD-S / VSD / MSSD / MSPD / AR | **bop_toolkit** —— [00_复现计划](../03-代码复现/00_复现计划.md) 目标 A 已选定，纯 Python + CPU 可跑 | ⬜ 待跑 |
| ADD / ADD-S 的 **AUC 口径**（YCB-Video，0–10cm） | **PoseCNN 官方代码**（仓库地址见 [PoseCNN 笔记](../01-笔记/PoseCNN-A%20Convolutional%20Neural%20Network%20for%206D%20Object%20Pose%20Estimation%20in%20Cluttered%20Scenes.md)） | ⬜ 待跑 |
| VBD | ⚠️ 这个名字只在 T8 待办里出现过，[03 表](03_数据集与指标表.md) 与三篇笔记都没有定义 | **[需核实:是 VSD 的笔误，还是另一个指标]** |
| 其余 | 先别找。读 P0 论文时遇到哪个补哪个 | — |

### 验收与落点

- 验收：能用一段话讲清 VSD 的计算流程；能解释「为什么 LM 与 LM-O 的差距 ≥30%」；能说出同一个 ADD-S 在两种口径下差多少。
- 落点：结论回填 [03_数据集与指标表](03_数据集与指标表.md) §二指标词典的「来源」列 —— 从「笔记未展开」升级为「已在源码中核对」。
- 代码与数据**不进本文件夹**，按 [00_复现计划](../03-代码复现/00_复现计划.md) §五的约定放在外部目录。
- 跑之前先过 `ecc-slim:code-reviewer`，跑完过 `ecc-slim:verification-loop`（种子、依赖版本、数据集路径写死在配置里）。

## 五、节奏与铁律

按 papers-notebook 的节奏模板，结合你的实际投入（每天约 1 小时）：

- **每日 1h**：新论文 : 复习笔记 = **3 : 2**（约 36 分钟读新的，24 分钟回头改笔记）。
- **每周精读 2~3 篇**，泛读不设上限。
- **周末**：更新 [05_研究缺口清单](05_研究缺口清单.md)，并问自己两句 —— 「这周搞懂了什么？」「还有什么没搞懂？」
- **每读完 3~5 篇**：回填 [01_论文总览矩阵](01_论文总览矩阵.md)。
- **每读完一个阶段**：写一篇 [02-阶段总结](../02-阶段总结/)，验收 = 能向别人讲清该阶段的贡献与漏洞。
- **P0 优先（2026-10-26 起）**：每天那 36 分钟先啃 P0 未读 9 篇；P2 经典链只在「卡住某个机制」时定向回查，回查不要求出完整笔记，但要在 [11_问题与待办](11_问题与待办.md) 记一行查到哪。

当前阶段配比建议：**泛读 : 精读 = 5 : 1**（第一个月），之后过渡到 2 : 1。
