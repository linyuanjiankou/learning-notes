# π₀.₅论文阅读复盘
1. π₀.₅对解决端到端具身机器系统在陌生环境下的长时间灵巧操作问题进行研究，通过异构数据训练VLA模型，提高模型在开放世界环境中的泛化能力。
2. 从文章内容中推断，相较于π0，π0.5围绕开放世界泛化重新考虑了数据来源、数据类型、数据混和方式、高层语义和低层动作之间的关系，在原有的VLA模型基础上引入了异构数据进行训练，使得其在新环境中的泛化性能更强。
3. π0.5将任务指令作为模型输入，通过VLA模型同时生成子任务和动作序列，然后机器人执行对应的动作序列。
4. 异构数据来源丰富，包括机器人数据，高层语义预测，网络数据和其它数据；机器人数据提供真实机器人动作，网络数据提供大量现实视觉与语义只是，高层语义数据帮助模型理解任务进程。
5. 使用机器人数据训练简单技能的方式不能完全套用在长进程任务的训练中，因此使用直接的移动灵巧平台和其他来源的数据可以扩大模型能够学习到的知识、语义和行为分布。
6. 开放世界泛化，意味着模型能够在训练阶段没有见过、或者与训练分布存在明显差异的环境、物体、任务组合中，仍然恩你个狗利用已有的知识完成任务。
7. 传统机器人使用高层子任务规划再加上底层动作生成两个步骤完成，而π0.5尝试将一个统一的模型同时承担高层语义决策与低层动作生成，而不是分成两个独立的系统。

# 今日目标：了解 Embodied AI 的技术路线

今天不要看具体代码。

搞清楚：

```
Computer Vision
       ↓
3D Perception
       ↓
Scene Understanding
       ↓
Robot Decision Making
       ↓
Planning
       ↓
Control
       ↓
Robot Action
```

然后理解另一条路线：

```
Image + Language
       ↓
     VLM
       ↓
     VLA
       ↓
Robot Action
```

你需要开始意识到：

> **6D Pose Estimation 并不是孤立的计算机视觉任务，而是机器人“理解物体在哪里、朝向哪里”的一种基础能力。**

例如：

```
Camera
  ↓
RGB-D
  ↓
Object Detection
  ↓
Object Segmentation
  ↓
6D Pose
  ↓
Grasp Planning
  ↓
Robot Arm
  ↓
Manipulation
```

这就是你未来可以逐渐走进去的一条路线。
