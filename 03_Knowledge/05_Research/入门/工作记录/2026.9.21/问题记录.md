# 整理总结
| 名词                                           | 解释                                                                                                                                                                                                                                                  |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Generalist robot manipulation policies       | 通用机器人操作策略。指一个模型或策略不是只做一个任务、一个物体、一个场景，而是能处理多种操作任务、多种物体、多种环境。传统做法常常是“一个任务训练一个策略”，而 generalist policy 希望一个策略就能抓盘子、开抽屉、叠衣服、清理桌面等。π0.5 就是一个 generalist robot manipulation policy，它能在新家庭中做多种家务任务。                                                         |
| fine-tuning pre-trained                      | 微调预训练模型。先在一个很大、很通用的数据集上训练一个模型，让它学到通用知识，然后在目标任务或目标机器人数据上继续训练，使它适应具体场景。比如 VLA 通常先基于预训练的视觉-语言模型，再用机器人动作数据微调。π0.5 也是先初始化自 VLM，再经过预训练和后训练适配机器人任务。                                                                                                        |
| highly expressive action decoding mechanisms | 高表达能力动作解码机制。机器人动作往往是连续、多峰、精细的，比如同一个任务可能有多种抓法，动作序列也很平滑。如果解码器太简单，就只能输出单一、平均化的动作，效果不好。高表达能力解码机制能表示复杂的动作分布，常见的有 diffusion、flow matching，以及一些高级动作 tokenization。π0.5 后训练阶段用 flow matching 作为动作解码机制。                                                       |
| flow matching                                | 一种生成模型，学习从随机噪声逐步流向真实数据的“速度场”。直观理解：给真实动作加噪声，训练模型预测如何把噪声推回真实动作；推理时从噪声出发，沿学到的方向积分几步，就得到连续动作序列。它和 diffusion 类似，但训练和推理可以更直接、更高效。π0.5 后训练阶段用 flow matching 生成连续低层动作 chunk，使动作更精细、更平滑，适合实时控制。                                                              |
| diffusion                                    | 扩散模型，一种生成模型。训练时不断给真实数据加噪声，让模型学会去噪；推理时从纯噪声开始，一步步去噪，最终生成数据。它在图像生成里很常见，在机器人里可以用来生成连续动作轨迹。diffusion 能表示多模态动作分布，比如绕过障碍物的多种路径，但推理通常需要多步去噪，可能比较慢。π0.5 论文把 diffusion 和 flow matching 都列为高表达能力动作解码机制。                                                        |
| advanced action tokenization schemes         | 高级动作 tokenization 方案。Tokenization 原本是把文本切成词，这里指把连续机器人动作变成离散 token 的方法。简单量化可能损失精度，高级方案会压缩动作序列、保留时间结构，让动作能像文本一样被 Transformer 自回归预测。π0.5 预训练阶段使用 FAST action tokenizer，把动作编码成离散 token，从而能在大规模异构数据上做 next-token prediction。                             |
| Non-robot data co-training                   | 非机器人数据共训练。指把机器人数据和非机器人数据混合在一起训练同一个模型。非机器人数据包括 Web 图像描述、视觉问答、物体检测、语言指令等。它们没有机器人动作，但能提供物体语义、场景常识和开放词汇知识。π0.5 的共训练配方就包含 Web 数据 WD 和高层子任务数据 HL，论文发现它们对 OOD 物体泛化和高层推理很重要。                                                                                |
| initialize vision encoders                   | 初始化视觉编码器。视觉编码器是把图像变成特征向量的网络，比如 ViT 或 CLIP 的视觉部分。机器人数据通常很少，所以常见做法是先用大规模计算机视觉数据集预训练视觉编码器，再把权重迁移到机器人策略中。这样机器人策略一开始就有不错的视觉理解能力。π0.5 的 VLM 主干初始化自 PaliGemma 这类预训练视觉-语言模型，也属于利用预训练视觉编码器知识。                                                                |
| off-the-shelf task planners                  | 现成的任务规划器。指不专门为当前机器人训练，而是直接拿来用的高层规划模块，比如用 GPT-4、LLM 或 VLM 把“清理厨房”分解成“拿起盘子”“放进水槽”等步骤。传统机器人系统常用这类 planner 做高层任务分解，再让低层策略执行。π0.5 的不同点是：它没有用单独的 off-the-shelf planner，而是用同一个 VLA 模型同时做高层子任务预测和低层动作生成。论文还比较了 GPT-4 作为高层策略的 baseline，发现效果不如 π0.5 自己学的高层推理。 |
