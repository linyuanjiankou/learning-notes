# 第一阶段：6D Pose 到底是什么

|#|论文|年份|作用|
|---|---|---|---|
|1|**BOP: Benchmark for 6D Object Pose Estimation**|2018|了解任务、数据集、评价指标|
|2|**PoseCNN**|2017|早期 RGB 端到端路线|
|3|**SSD-6D**|2017|早期 RGB + 模板/渲染路线|
|4|**DeepIM**|2018|理解 Pose Refinement|
|5|**MR6D: Benchmarking 6D Pose Estimation for Mobile Robots**【2025】|2025|面向移动机器人的新基准，覆盖远距离视角、大尺寸物体、自遮挡等传统数据集忽略的挑战[](https://www.openaccess.thecvf.com/content/ICCV2025W/R6D/html/Gouda_MR6D_Benchmarking_6D_Pose_Estimation_for_Mobile_Robots_ICCVW_2025_paper.html#1)|
|6|**Monocular RGB 6D Object Pose Estimation for AR: A Survey**【2026】|2026|面向 AR 场景的单目 RGB 位姿估计综述，梳理现代深度学习方法的最新格局|

**本阶段新增说明**：BOP 仍然是理解评测体系的起点。MR6D 的价值在于它揭示了传统 household 数据集与真实移动机器人场景之间的差距——当前 6D pipeline 在远距离、大物体、自遮挡条件下性能显著下降[](https://www.openaccess.thecvf.com/content/ICCV2025W/R6D/html/Gouda_MR6D_Benchmarking_6D_Pose_Estimation_for_Mobile_Robots_ICCVW_2025_paper.html#1)。AR 综述则帮助你理解单目 RGB 路线在应用侧的最新边界。

# 第二阶段：理解“2D → 3D → Pose”的核心路线

|#|论文|年份|核心问题|
|---|---|---|---|
|5|**PVNet**|2019|像素级投票寻找关键点 + PnP 恢复 Pose|
|6|**CDPN**|2019|RGB → object coordinates → Pose|
|7|**DPOD**|2019|Dense correspondence 用于 6D Pose|
|8|**Pix2Pose**|2019|像素级坐标回归建立 2D–3D 对应|
|9|**EPro-PnP**【进阶】|2022|PnP 与深度学习的可微分融合|
|10|**Corr2Distrib: Making Ambiguous Correspondences an Ally to Predict Reliable 6D Pose Distributions**【2025】|2025|首个从 RGB 图像估计 6D 位姿**分布**的对应关系方法，将对应关系中的模糊性从“敌人”转化为“盟友”|
|11|**Resolving Symmetry Ambiguity in Correspondence-Based Methods**【2025】|2025|专门解决对应关系方法在**对称物体**上的歧义问题，提出 SymCode 表示|

**本阶段新增说明**：PVNet 到 Pix2Pose 建立的核心认知是“网络先预测几何信息，再用几何算法求 Pose”。2025 年的 Corr2Distrib 在此基础上更进一步——它不再只输出一个点估计，而是输出一个**位姿概率分布**，这对理解“对应关系为什么会有歧义”以及“如何量化位姿不确定性”非常有帮助。对称性歧义是 correspondence-based 方法长期存在的痛点，第 11 篇提供了专门的解决方案。

|#|论文|年份|核心问题|
|---|---|---|---|

|13|**CosyPose**|2020|多视角 + 多物体 + 全局一致性|

|17|**RACE-6D: Real-time Accurate Coarse-to-finE Object 6D Pose Transformer**【2026】|2026|Transformer 架构下的实时粗到细位姿估计，代码已开源|
|18|**AlignPose: Generalizable 6D Pose Estimation via Multi-view Feature-metric Alignment**【2026】|2026|多视角特征度量对齐，无需物体特定训练或对称标注，在工业多视角场景中表现突出[](https://openaccess.thecvf.com/content/CVPR2026/html/Mikestikova_AlignPose_Generalizable_6D_Pose_Estimation_via_Multi-view_Feature-metric_Alignment_CVPR_2026_paper.html#1)|
|19|**SDT-6D: Fully Sparse Depth-Transformer for Industrial Multi-View Bin Picking**【2026】|2026|全稀疏深度 Transformer，专门应对工业 bin-picking 中的密集堆叠、反射和弱纹理|

**本阶段新增说明**：DenseFusion 到 ZebraPose 建立了 RGB-D 融合、多视角一致性、几何引导回归的完整认知链条。2026 年的三篇新工作各有侧重——RACE-6D 关注**实时性**，AlignPose 强调**多视角泛化且无需物体特定训练**，SDT-6D 则把问题推向**工业 bin-picking 的极端遮挡和弱纹理场景**。AlignPose 在 YCB-V、T-LESS、HouseCat6D、ITODD-MV、IPD、XYZ-IBD 六个数据集上使用 BOP 评测，在工业数据集上优势尤为明显[](https://openaccess.thecvf.com/content/CVPR2026/html/Mikestikova_AlignPose_Generalizable_6D_Pose_Estimation_via_Multi-view_Feature-metric_Alignment_CVPR_2026_paper.html#1)。

|#|论文|年份|核心问题|
|---|---|---|---|
|20|**NOCS**|2019|Category-level canonical coordinate space|
|21|**SGPA**|2021|Category-level pose 为什么需要 shape prior|

|23|**HouseCat6D**|2024|大规模多模态 category-level 数据集|

|25|**SEGPose: SE(3)-Equivariance with Geometric and Topological Guidance for Category-Level Object Pose Estimation**【2026】|2026|首个同时引入**几何特征、拓扑特征和 SE(3)-等变性**的纯深度（点云）category-level 方法|
|26|**DG-6D: Dual-stream Geometric Feature Fusion and Global Enhanced Key-point Feature Extraction**【2025】|2025|双流几何特征融合 + 全局增强关键点特征，在 HouseCat6D、REAL275、CAMERA25 上全面达到 SOTA|

**本阶段新增说明**：NOCS 和 SGPA 建立了 category-level pose 的基础范式。Diff-COPE 代表了 2025 年的一个重要转向——**用扩散模型替代 mean shape prior**，通过可学习关键点和条件去噪过程更好地适应类内形状变化[](https://ieeexplore.ieee.org/abstract/document/11177583#1)。SEGPose 则从几何和拓扑的视角重新审视 category-level 问题，SE(3)-等变性的引入意味着对旋转的建模方式发生了根本性变化。

# 第五阶段：Novel Object —— 最值得重点关注的区域

|#|论文|年份|核心问题|
|---|---|---|---|
|27|**OnePose**|2022|无需 CAD，用 RGB video 扫描物体|
|28|**OnePose++**|2022|低纹理物体的 keypoint-free matching|
|29|**MegaPose**|2023|Render & Compare 泛化到未见物体|
|30|**FoundationPose**|2024|统一 model-based / model-free，pose estimation + tracking|
|31|**BundleSDF**|2023|连 CAD 都没有时的 tracking + 3D reconstruction|
|32|**Any6D: Model-free 6D Pose Estimation of Novel Objects**【2025】|2025|仅需**单张 RGB-D anchor image**即可估计未知物体的 6D 位姿和尺寸，无需 textured 3D model 或多视角[](https://ieeexplore.ieee.org/abstract/document/11092592)|
|33|**PoseGAM: Robust Unseen Object Pose Estimation via Geometry-Aware Multi-View Reasoning**【2026】|2026|几何感知多视角框架，直接预测位姿而**无需显式匹配**，构建了 190k+ 物体的合成数据集，平均 AR 提升 5.1%[](https://openaccess.thecvf.com/content/CVPR2026/html/Chen_PoseGAM_Robust_Unseen_Object_Pose_Estimation_via_Geometry-Aware_Multi-View_Reasoning_CVPR_2026_paper.html#1)|
|34|**RayPose: Ray Bundling Diffusion for Template Views in Unseen 6D Object Pose Estimation**【2025】|2025|将扩散 Transformer 用于 query image 与 posed templates 的对齐，将扩散式位姿估计从相机位姿扩展到未见物体位姿|
|35|**UA-Pose: Uncertainty-Aware 6D Object Pose Estimation and Online Object Completion with Partial References**【2025】|2025|专门处理**部分参考**（partial reference）场景，在估计位姿的同时在线补全物体几何，并输出不确定性估计|

**本阶段新增说明**：OnePose → OnePose++ → MegaPose → FoundationPose → BundleSDF 这条链建立了 Novel Object 位姿估计的完整认知。2025–2026 年的新工作沿着几个方向推进：

- **Any6D** 把参考输入压缩到**单张 RGB-D 图像**，大幅降低了部署门槛，并在 REAL275、ToyotaLight、HO3D、YCBINEOAT、LM-O 五个数据集上验证[](https://ieeexplore.ieee.org/abstract/document/11092592)。
    
- **PoseGAM** 用多视角 foundation model 架构 + 几何编码，**取消显式匹配步骤**，代表了“从匹配范式到直接预测范式”的转变[](https://openaccess.thecvf.com/content/CVPR2026/html/Chen_PoseGAM_Robust_Unseen_Object_Pose_Estimation_via_Geometry-Aware_Multi-View_Reasoning_CVPR_2026_paper.html#1)。
    
- **UA-Pose** 引入了 **uncertainty-aware** 的视角，同时做位姿估计和在线几何补全，对机器人场景中“部分观测”的现实问题非常有针对性。
    
- **RayPose** 将扩散模型从相机位姿估计迁移到未见物体位姿估计，是一种方法论上的迁移创新。

|42|**UnPose: Uncertainty-Guided Diffusion Priors for Zero-Shot Pose Estimation**【2025】|2025|用多视图扩散模型估计初始 3D 模型（3D Gaussian Splatting 表示）+ 像素级 epistemic uncertainty，随观测增加持续精化|

**本阶段新增说明**：SAM-6D 和 Open-Vocabulary Object 6D Pose Estimation 建立了“基础模型 + 开放词汇”进入 6D pose pipeline 的基本范式。2025 年的新工作沿着三条线展开：

- **CLIP-6D** 把 CLIP 从“特征提取器”转变为“位姿估计器”，核心挑战是 CLIP 本身缺乏 pose awareness，论文用自对齐和知识蒸馏来弥补[](https://dl.acm.org/doi/abs/10.1145/3746027.3754497#1)。

- **UnPose** 结合了扩散先验 + 3DGS + 不确定性估计，把“开放世界中的位姿估计”与“在线 3D 重建”和“不确定性量化”串联起来，技术栈最为综合。

**整体趋势判断**：2025–2026 年该领域最明显的三个转向是——(1) **扩散模型**从相机位姿估计迁移到物体位姿估计（Diff-COPE、RayPose、UnPose）；(2) **基础模型**（CLIP、DINOv2、SAM、多视角 foundation model）以零样本或开放词汇的形式进入位姿估计 pipeline；(3) **不确定性量化**和**部分观测**成为 Novel Object 方向的新焦点（UA-Pose、UnPose、Conformal Keypoint）。如果你之前关注的 embodied AI / open-world generalization 方向，第五、第六阶段的新增论文应该是最值得优先精读的。
