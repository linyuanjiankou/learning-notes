# 问题解释
| 名词                             | 中文             | 解释                  | 在 6D Pose 中的作用 / 例子                           |
| ------------------------------ | -------------- | ------------------- | --------------------------------------------- |
| pipeline                       | 流程 / 流水线       | 从输入到输出的完整处理步骤       | 输入 RGB-D → 分割 → 特征/对应 → 位姿假设 → 优化 → 输出 R,tR,t |
| benchmark                      | 基准测试           | 标准数据集 + 评价指标 + 评估协议 | LineMOD、YCB-Video、BOP；ADD(-S)、VSD、MSSD 等      |
| RGB-D                          | 彩色-深度图像        | RGB 彩色图 + Depth 深度图 | RGB 提供纹理，Depth 提供几何，融合估计 6D 位姿                |
| texture-mapped 3D object model | 带纹理映射的 3D 物体模型 | 3D mesh + 表面纹理      | 渲染训练数据、提取特征、建立 2D-3D 对应、计算 ADD                |
| pose-error function            | 位姿误差函数         | 衡量估计位姿与真实位姿差异       | ADD、ADD-S、旋转误差、平移误差、重投影误差                     |
| pose ambiguities               | 位姿歧义 / 模糊      | 多个位姿产生相似观测，难以唯一确定   | 对称物体、无纹理、重复纹理；用 ADD-S、多假设等处理                  |
| point-pair features            | 点对特征 / PPF     | 用一对 3D 点及法线构造的几何描述子 | 匹配模型和场景点对，投票生成 6D 位姿假设，适合 RGB-D/点云            |
