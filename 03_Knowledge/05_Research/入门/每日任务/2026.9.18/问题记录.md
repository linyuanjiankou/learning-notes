# 整理解释
|名词|一段解释|
|---|---|
|低层动作 chunk|指模型不是每一步只输出一个动作，而是一次输出未来一小段动作序列 at:t+Hat:t+H​。π0.5 中一次输出 50 步动作，约 1 秒，控制频率 50Hz。低层指的是具体机器人控制指令，如关节目标、末端执行器目标位姿、夹爪、躯干升降和基座速度。|
|预训练阶段：离散 token + 自回归 next-token prediction + FAST action tokenizer|π0.5 的第一阶段训练。它把图像、语言、检测框、动作等数据都统一成 token 序列，用“给定前面的 token，预测下一个 token”的自回归方式训练。由于机器人动作原本是连续值，就用 FAST action tokenizer 把连续动作压缩、量化成离散 token，让动作能像文本一样参与大规模预训练。|
|Action Expert|Action Expert 是 Transformer 中专门负责动作生成的一组专家权重，参数比 VLM 主干小。它接收带噪声的动作 token，输出 flow matching 的向量场，用来生成连续动作 chunk。它和 VLM 主干通过 self-attention 交互，但信息基本是单向的：VLM 的信息流向 Action Expert。|
|Flow Matching|一种生成模型，学习从随机噪声逐步流向真实动作的“速度场”。训练时给真实动作加噪声，让模型学习如何从噪声恢复动作；推理时从噪声开始，沿学习到的方向积分几步，就得到连续动作序列。π0.5 后训练阶段用它生成更精细、更平滑的低层动作 chunk。|
|具身 Chain-of-Thought|让机器人先“想一下下一步做什么”，再输出具体动作。π0.5 先根据观测和总任务预测高层子任务，例如“拿起盘子”，再基于这个子任务预测低层动作 chunk。它类似语言模型里的思维链，但高层推理频率低于低层动作推理。|
|End-to-End Robot Control|端到端机器人控制，指从传感器输入直接学到控制指令，中间不手工设计检测、6D Pose、任务规划、运动规划等模块。π0.5 虽然先输出高层子任务，但高层和低层都由同一个模型学习，低层直接输出目标位姿和速度，没有额外轨迹规划或碰撞检测。|
|Hybrid Multi-modal Examples|混合多模态训练样本，指训练样本格式不单一，可能同时包含图像观察、语言命令、物体检测、语义子任务预测、低层动作、Web 问答等。这些不同格式的样本会被统一成 token 序列，让同一个模型一起学习。|
|Training Recipes|训练配方或课程表，包括数据怎么混合、分几个阶段训练、用什么损失、动作怎么表示、超参数怎么设置等。π0.5 的核心贡献之一就是这套共训练配方，而不只是模型结构。|
|Dexterous Manipulation Skills|灵巧操作技能，指需要精细、多自由度、协调控制的任务，例如铺床、把餐具放进水槽、把衣服放进洗衣篮、开关抽屉、整理枕头、擦洒出物、挂毛巾等。π0.5 能在训练中未见过的新家庭里执行这些长时程、多阶段任务。|
