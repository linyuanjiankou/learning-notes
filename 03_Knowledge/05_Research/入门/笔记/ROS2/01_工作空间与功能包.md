# 基本概念
## 工作空间
> 存放项目开发相关文件的文件夹，开发过程的大本营
### 内置子空间
- src：代码空间
- install：安装空间
- build：变异空间
- log：日志空间
### 创建&编译工作空间
- 创建工作空间：
```shell
mkdir -p ~/my_dev/src && cd ~/my_dev/src
```
- 自动安装依赖
```shell
sudo rosdepc init && rosdepc update
cd ~/my_dev
rosdepc install -i --from-path src --rosdistro humble -y
```
- 编译工作空间
```shell
cd ~/my_dev
colcon build
```
- 设置环境变量
```shell
source install/local_setup.sh
```
> 关于设置环境变量的问题，理论上说，每次打开该项目都要执行一遍设置环境变量的指令，但是为了方便管理，有多种简易的管理方式写入.bashrc文件；
> 鉴于我目前项目较少，我使用 `alias myros='cd /media/zhou/B8822DF4822DB7B0/Profile/02_My_DevSpace/01_Lab/ROS2/my_dev && source install/local_setup.sh` ，（包含跳转到项目工作空间并设置环境变量两个指令）
> 这种类似于取别名的方式进行，
> 每次只需要在终端输入 `mydev` 就可以设置该项目的环境变量，如果之后项目较多的话可以写入函数来管理。
### 创建&编译功能包
- 创建功能包
```shell
cd ~/my_dev/src
ros2 pkg create --build-type ament_cmake learning_pkg_c #C++
ros2 pkg create --build-type ament_python learning_pkg_python # python
# 满足以下格式：
ros2 pkg create --build-type <build-type> <package_name>
```
- 编译功能包
```shell
cd ~/my_dev/src
colcon build # 编译工作空间所有功能包
source install/local_setup.bash #或者使用设置好的别名
```
# 注意
## 创建接口包
使用cmake方式创建好接口包之后需要两个注册步骤：
1. ** 修改 `CMakeLists.txt`**：在文件末尾 `ament_package()` 这一行**之前**，补上：
```cmake
find_package(rosidl_default_generators REQUIRED)

rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/StudentInfo.msg"
)
```
2. **修改 `package.xml`**：在 `<package>` 标签内（比如 `<test_depend>` 附近）补上三个标签：
```xml
<buildtool_depend>rosidl_default_generators</buildtool_depend>
<exec_depend>rosidl_default_runtime</exec_depend>
<member_of_group>rosidl_interface_packages</member_of_group>
```
