# 简介
在ROS2中，节点之间可以进行通信，数据被发送到共享的数据总线上，需要数据的节点从中获取。
ROS2将 Topic, Service, Action 统称为接口，各自解决了不同层面的问题。

|接口类型|文件后缀|通信模式|适用场景|
|---|---|---|---|
|**Topic（话题）**|`.msg`|发布-订阅（异步、单向）|持续数据流，如传感器数据发布|
|**Service（服务）**|`.srv`|请求-响应（同步/异步）|短时功能调用，如参数查询、状态设置|
|**Action（动作）**|`.action`|任务执行（带反馈和取消）|长时间运行任务，如导航、机械臂控制|
# 查看
在ROS2系统中，我们支持通过命令行指令来进行查看：
- `ros2 interface list`: 列出所有接口
- `ros2 interface show <接口名>`: 查看接口详细定义
- `ros2 interface package <包名>`: 查看包内所有接口
- `ros2 interface proto <接口名>`: 查看接口完整结构
# 注意
当我们定义完成通信接口中需要传输的数据之后，需要将该文件名存放到 `CMakelists.txt` 文件中。
通信接口符合自己的格式，不同功能的数据区之间需要使用三横线 `---` 换行分割开。
