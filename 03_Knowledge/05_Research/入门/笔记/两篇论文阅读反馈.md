# 一、宏观方向对比
## 相同点：
本质上，这两篇论文都是在讨论如何提高机器人在实用场景下的泛化能力，使其能够在陌生环境和陌生物体上工作。
## 不同点：
1. 从实现方式上面来说，$\pi_{0.5}$ 从多源海量数据进行端到端学习训练，对新物体采取迁移和类比的方式进行迁移；而RSRD通过学习已有用户的演示视频，在识别新物体的位置、形状和姿态之后推理出运动轨迹。
2. 从数据量上来说，$\pi_{0.5}$ 使用了大量机器人数据进行训练（包括400h真实房屋数据，互联网数据和语义指令数据等），而RSRD只需要一次扫描加上单目视频。
3. 从成功率上来看，$\pi_{0.5}$ 成功率较高，长时程任务表现较好；对于RSRD来说，各部分平均成功率较高（87%），但是综合端到端成功率一般（60%）
# 二、论文1：$\pi_{0.5}$
## 核心问题
探讨end-to-end learning-enabled robotic system在实际场景中完成长时程任务的可行性
## 核心思路
- 核心模型：VLA（由VLM模型训练演变而来）
- 两个阶段训练：pre-train -> fine-tune
- 工作流程：predict semantic subtasks -> infer the behavior -> predict the low-level action chunk（high-level 语义理解分配子任务 + low-level 控制动作）
- 训练数据：heterogeneous co-training: 使用网络数据提高high-level的语义理解能力；使用其他机器人数据训练low-level提高动作准确度
## 重要结论
- 在陌生新家中能够执行10-15分钟的复杂多阶段行为（~~打扫厨房和卧室~~）
- 训练环境越多，泛化能力越好
- laboratory cross-embodiment data 和 multi-environment nonmobilde data 这两个种类的数据对系统性能影响较大（CE, ME）
- High level inference 能显著提升成功率，即使尽在训练时加入HL数据而不引用在推理过程也有正向作用
# 三、论文2：RSRD
## 核心问题
探究如何让机器人通过演示的单目视频，就能复现该物体的运动，且不针对任务做任何预训练。
## 核心思路
1. 4D-DPM (4D Differentiable Pard Model)
	物体的多视角静态扫描 -> GARField + 3D Gaussian Splat -> 嵌入DINO feature field
2. 通过预测物体运动轨迹而不是学习人手运动轨迹，
3. 执行阶段：
	- Init.：物体位置和姿态的初始化（93%）
	- Traj.：无碰撞轨迹规划（91%）
	- Grasp：抓取执行（82%）
	- Exec.：运动执行（86%）
## 实验结果
- 端到端成功率约为60%
- 使用DINO特征作为鲁棒优化目标的ARAP显著由于纯光度跟踪
## 局限性
- 对物体初始姿态和演示时的姿态的差异较为敏感
- 存在手动切割阶段，可以优化成自动化
- 对物体扫描质量和演示镜头视角要求较高
- 难以处理部分对象的自遮挡
- 在对称性高、特征少或者较小的物体上表现不佳
## 我的问题
在文章开头中提到的60%的端到端成功率是由于方法的上限不高，还是可优化空间较大？
在四个阶段当中，抓取阶段和运动阶段的成功率相较前面两个阶段较弱，是否可以通过一些办法来提高成功率？比如说闭环控制，或者像 $\pi_{0.5}$ 中那样训练一个VLA模型来进行抓取和运动执行。
