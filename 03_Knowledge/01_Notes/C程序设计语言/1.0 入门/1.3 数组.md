为了统计各个数字、空白符（包括空格符、制表符、换行符）以及其它字符出现的次数。虽然这个程序的实用意义并不大，但我们可以通过该程序讨论C语言多方面的问题。

所有的输入字符可以通过12类，因此可以用一个数组存放各个数字出现的次数，这样比使用10个独立的变量更方便，以下是该程序的一个版本。

```c
#include <stdio.h>
int main(){
	int c, i, nwhite, nother;
	int ndigit[10];
	
	nwhite = nother = 0;
	for (i = 0; i < 10; ++i){
		ndigit[i] = 0;
	}
	
	while ((c = getchar()) != EOF){
		if (c >= '0' && c <= '9') ++ndigit[c-'0'];
		else if (c == ' ' || c == '\n' || c == '\t') ++nwhite;
		else ++nother;
	}
	printf("digits =");
	for (i = 0; i < 10; ++i){
		printf(" %d", ndigit[i]);
	}
	printf(", white space = %d, other = %d\n", nwhite, nother);
}
```

关于`c - '0'`：由于数字字符以ASCII码的形式连续存储，所以当c是数字字符时，减去0所代表的ASCII码，则刚好对应真实数字字符的值，作为数组的下标。
