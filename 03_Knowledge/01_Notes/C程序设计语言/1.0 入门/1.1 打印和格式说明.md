## 打印宽度
当输出内容为多个数据占一行时，为了整洁美观，可以规定打印时的数字宽来达到右对齐的效果。例如：`printf("%3d %6d\n", a, b)`。
其中，a的值占3个数字宽，b的值占6个数字宽

## 格式说明
| 格式说明  | 具体解释                      |
| ----- | ------------------------- |
| %d    | 按照十进制整型数打印                |
| %6d   | 按照十进制整型数打印，至少6个字符宽        |
| %f    | 按照浮点数打印                   |
| %6f   | 按照浮点数打印，至少6个字符宽           |
| %.2f  | 按照浮点数打印，小数点后由两位小数         |
| %6.2f | 按照浮点数打印，至少6个字符宽，小数点后由两位小数 |
| %o    | 按照八进制数打印                  |
| %x    | 按照十六进制数打印                 |
| %c    | 按照字符打印                    |
| %s    | 按照字符串打印                   |
| %%    | 表示百分号(%)本身                |
