在C语言的标准库中提供了一次读/写一个字符的函数，最简单的分别是`getchar()`和`putchar()`这两个函数。

标准库提供的输入 / 输出模型比较简单，文本的输入 / 输出都是按照字符流的方式处理。文本流是由多行字符构成的字符序列，每行字符由0或多个字符组成，行末是一个换行符。

`getchar()`函数回读取一个字符并返回，失败或到达末尾 (EOF) 时，返回EOF（通常为-1），可以读取空格、换行符等所有ASCII字符；`putchar()`函数将一个字符写入到标准输出，失败时返回EOF。这两个函数都被定义在 <stdio.h> 头文件中，两者循环结合可以实现简单的回显。

# 文件复制
字符在机器内部以位模式存储。`char`类型专门用于存储这种字符型数据，当然任何整型（int）也可以用于存储字符型数据。这里由于要处理EOF，所以使用 int 类型来接收字符。
```c
int main(){
	int c;
	while ((c = getchar()) != EOF){
		putchar(c);
	}
	return 0;
}
```
在以上程序中可以发现，我们为`c = getchar()`套上了一个括号，这是由于`!=`的优先级高于赋值符`=`，如果不套上括号的话，c就会被赋值为0 / -1，与我们原本程序逻辑相悖。

# 字符计数
```c
int main(void){
	long nc = 0;
	while (getchar() != EOF){
		++nc;
		printf("%ld\n", nc);
	}
}
```

# 行计数
由于标准库保证输入文本流以行序列的形式出现，每一行以换行符结束。因此，统计行数等价于统计换行符的个数。
```c
int main(void){
	int c, nl;
	nl = 0;
	while ((c = getchar()) != EOF){
		if (c == "\n") ++nl;
	}
	printf("%d\n", nl);
}
```
