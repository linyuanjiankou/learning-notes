元组是Python中的一种数据类型，用于创建有序的值序列。元组可以包含字符串、数字等混合的数据类型。

但与列表不同的是，列表是可变的数据类型，而元组是不可变的。如果你尝试更新元组中的某一项，你会得到一个`TypeError`。
```python
developer = ('Alice', 34, 'Rust Developer')
developer[0] = 'Alex' # TypeError: 'tuple' object does not support item assignment
```

要想访问元组中的元素，可以使用方括弧索引，当然，元组支持负索引访问。如果输入的索引号大于等于元组的长度，你会收到一个`IndexError`。
```python
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
numbers[7] # IndexError: tuple index out of range
```
