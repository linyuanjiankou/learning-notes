# 一、字符串
## 引号处理
在某些编程语言中，被单引号和被双引号包裹的字符串处理并不相同，然而在Python中，两者被视为相等。除此之外，你也可以使用三重双引号或单引号来表示多行字符串：
```python
my_str_1 = "Hello"
my_str_2 = 'World'
my_str_3 = """Multiline
string"""
my_str_4 = '''Another
multiline
string'''
```
当遇到将引号视为一部分字符，即引号中套引号的情况时，通常有两种情况进行处理：
- 使用相反类型的引号。也就是说，如果外面使用双引号，内部使用单引号，反之亦然。
```python
msg = "It's a sunny day"
quote = 'She said, "Hello World!"'
```
- 用反斜线`\`转换字符串中的单引号或双引号（这种处理方法莫名有种LaTex的感觉）
```python
msg = 'It\'s a sunny day'
quote = "She said, \"Hello World!\""
```
## 包含检查
有时，你需要检查字符串中是否存在某一个字符或者某一段字符串，Python提供的`in`操作符通过返回一个布尔值，指定该字符或字符串是否存在于指定字符串中
```python
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```
## 索引
有时，我们需要获取字符串的长度并处理字符串中的单个字符，这个过程被称为索引，要获取字符串的长度，我们可以使用Python的内置函数——`len()`函数。
```python
my_str = 'Hello world'
print(len(my_str))  # 11
```
字符串的每一个字符都有一个称为索引的位置。索引都是从零开始的，这意味着字符串中第一个字符的索引是0，第二个字符的索引是1，以此类推。你可以使用方括弧`[]`来指定索引位置。
~~感觉可以把字符串视为一个不可变的数组，每一个字符按顺序存入一个数组位~~
然而，不同的是，Python支持负索引，即可以使用`-1`表示最后一个字符，以此类推。
```python
my_str = "Hello world"

print(my_str[0])  # H
print(my_str[6])  # w
print(my_str[-1])  # d
print(my_str[-2]) # l
```
# 二、不可变性
许多编程语言将数据类型大致分为原生类型或引用类型。
- 原生类型简单且不可变，一旦声明就不能更改
- 引用类型可以包含很多值，并且可以是可变或不可变的。
然而，Python不在这两者之间做区分，所有数据都被视为对象，有些对象可变，有些对象不可变。
字符串就是Python中不可变数据类型。你可以通过赋值来为变量赋值不同字符串，但是不允许直接直接修改字符串。
```python
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello

greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```
Python中其他不可变的数据类型包括 **整数、浮点数、布尔、元组和范围**
