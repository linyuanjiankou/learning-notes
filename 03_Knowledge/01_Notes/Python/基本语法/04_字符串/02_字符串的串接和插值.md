# 一、串接
在Python中，你可以通过使用加号（`+`）操作符将多个字符串串接在一起。
```python
my_str_1 = 'Hello'
my_str_2 = "World"

str_plus_str = my_str_1 + ' ' + my_str_2
print(str_plus_str) # Hello World
```
当然，串接只是用于字符和字符串之间，例如不能直接将字符串和数字串接在一起。当然，你可以将数字通过`str()`函数强制转化为字符串后再串接，这种方法不会改变原始对象，只返回给定对象的字符串表现形式。
```python
name = 'John Doe'
age = 26

name_and_age = name + str(age)
print(name_and_age) # John Doe26
```
你也可以使用扩充赋值操作符（`+=`）来进行串接。
```python
name = 'John Doe'
age = 26

name_and_age = name  # Start with the name
name_and_age += str(age)  # Append the age as string

print(name_and_age)  # John Doe26
```
# 二、插值
将变量和表达式插入到字符串的过程称为 **字符串插值** 。
Python有一类称为 **f-strings**（格式化字面值）的字符串，它允许你用简洁且可读的语法来处理插值。
f-strings以 `f/F` 开头，紧跟引号，允许你在由花括号（`{}`）表示的替换字段中嵌入变量或表达式。
```python
name = 'John Doe'
age = 26
name_and_age = f'My name is {name} and I am {age} years old'
print(name_and_age) # My name is John Doe and I am 26 years old

num1 = 5
num2 = 10
print(f'The sum of {num1} and {num2} is {num1 + num2}') # The sum of 5 and 10 is 15
```
在使用 f-strings 进行字符串插值时，不需要使用 `str()` 函数转换非字符串的数据类型，非字符串变量会在插值过程中在底层被转换为字符串。
