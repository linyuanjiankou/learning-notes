# 一、字符串切片
在之前的文章中，我们介绍了如何通过索引识别字符串中的每一个字符，并使用方括号进行访问，在此基础上，我们继续学习字符串切片的相关内容。
通过字符串切片，你能够提取字符串的一部分或仅处理其中的特定部分，其基本语法如下：
```python
string[start:stop:step]
```
其中，`start`表示提取的起始位置，`stop`表示提取的结束位置，`step`表示提取步长，切片提取的范围是`[start, stop)`
通常来说，可以舍去`step`不写，这时候默认步长为1。
```python
my_str = 'Hello world'
print(my_str[1:4]) # ell
```
你也可以省略`start`和`stop`索引，Python会分别默认使用`0`或者字符串的末尾进行填充。例如：
```python
my_str = 'Hello world'
print(my_str[:7])  # Hello w

print(my_str[8:])  # rld

print(my_str[:])  # Hello world
```
**注意：** *切片不会修改原始字符串*
对于步长，你可以设置为`2`，每个一个字符进行提取；你甚至可以设置为`-1`，来对特定部分的字符串进行反转。
```python
my_str = 'Hello world'
print(my_str[0:11:2])  # Hlowrd

print(my_str[::-1]) # dlrow olleH
```
