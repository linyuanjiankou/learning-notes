从某种程度上说，函数其实就是可以复用的代码片段，当调用它们的时候就会运行。许多编程语言会内置一些函数，Python中也有，除了之前提到的`print()`打印函数，另一个比较有用的函数是`input()`输入函数，功能表现类似于C中的`scanf()`：

```python
name = input('What is your name?') # User types "Kolade" and presses Enter  
print('Hello', name) # Output: Hello Kolade
```

当然，你也可以自定义一些函数。为此，你需要使用`def`关键字，后面跟上给函数命名的名称，一对括号和冒号。然后在换行编写你的函数对应代码。函数运行的代码也称为函数的体。

```python
def hello():
	print("Hello World")
```

当然调用的时候也非常简单，直接书写它的名称加一对括号即可。
```python
hello() # Hello World
```

如果你的函数运行依赖一些外部传入的参数，你可以在函数名称后面的括号中定义变量（形参），调用的时候也同样在括号内按顺序写入对应变量的值即可（实参）。当传入多变量的时候，几个变量之间需要用逗号分隔。

以下是一个调用`calculate_sum`函数来进行两个数字相加的函数：
```python
def calculate_sum(a, b):
	print(a + b)
	
calculate_sum(3, 1) # 4
```

函数还使用特殊的`return`关键字来退出函数并返回一个值，如果你不显式使用`return`关键字，则函数默认返回`None`
