对于整数和浮点数，我们可以进行一些算术计算。

对于纯整数和纯浮点数计算，直接使用算术符号`+-*/`进行加减乘除计算即可，输出也会分别是整数和浮点数。

如果将整数和浮点数进行混合计算，区别于C语言需要强制转换，Python会自动转换为浮点数，然后输出浮点数作为结果。

对于一些稍复杂的计算，其计算方法如下：
1. 取模运算符`%`：返回左侧值除以右侧值时的余数。
2. 地板除法`//`：将两个数字相除并返回小于等于结果的最大整数。
```python
my_int_1 = 56
my_int_2 = 12

my_float_1 = 5.4
my_float_2 = 12.0

floor_div_ints = my_int_1 // my_int_2
floor_div_floats = my_float_2 // my_float_1

print('Integer Floor Division:', floor_div_ints) # Integer Floor Division: 4
print('Float Floor Division:', floor_div_floats) # Float Floor Division: 2.0
```
3. 指数运算`**`：将一个数字提升到另一个数字的幂。

有时，你可能会注意到涉及浮点数的运算结果比预期有更多小数位，例如，`0.1 + 0.2` 的和等于 `0.30000000000000004`，而不是 `0.3`。

这是因为数字以二进制形式保存，而某些分数无法在二进制中被精确表现。因此，它们被保存为有限的近似值，就像分数 `1/3` 无法用有限位数的十进制数字表现一样，并且在其无限数字（`0.33333...`）的某个位置被截断。

这会导致小的舍入误差。

Python还提供了用于将数字数据或字串转换为整数或浮点数的内置函数。我的理解是类似于C语言的强制转换。区别在于，C语言的强制转换一般是临时性的读取转换，Python是创建一个新的数据对象。在Python中，整数型可以和浮点数互相强制转换，也可以将字符串转换为浮点数或整数。

以下列举了一些Python提供的用于处理整数和浮点数的一些其他方法：

 - `round()`：将数字四舍五入到指定的小数位数。默认情况下，此函数将数字四舍五入到最接近的整数，并返回没有小数位的整数：
```python
my_int_1 = 4.798
my_int_2 = 4.253

rounded_int_1 = round(my_int_1)
rounded_int_2 = round(my_int_2, 1)

print(rounded_int_1) # 5
print(rounded_int_2) # 4.3
```

- `abs()`：返回一个数字的绝对值。

- `pow()`：将一个数字提升到另一个数字的幂，或执行模幂运算。
```python
result_1 = pow(2, 3)  # Equivalent to 2 ** 3
print(result_1)  # 8

result_2 = pow(2, 3, 5)  # (2 ** 3) % 5
print(result_2)  # 3
```
