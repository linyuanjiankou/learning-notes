# 一些基本概念
Numpy 的对象是同质多维数组，它是一个由具有相同类型的元素（通常是数字）组成的表格，由非负整数组成的元组索引。在Numpy中，维度也被称为 ”轴“ 。

一个轴包含几个元素，我们就说它的长度为几。

例如，在下面这个示例中：
```python
[[1., 0., 0.],
[0., 1., 2.]]
```
这个数组一共有两个轴，第一个轴的长度为2，第二个轴的长度为3。

*轴按照从外到里，从高维到低维的顺序进行排序*

Numpy 的数组类名为 `ndarray`。它也被称为 `array`。

注意，`numpy.array` 与标准 Python 库类 `array.array` 不同，后者仅处理一维数组而且功能较少。

# ndarray对象属性
1. `ndarray.ndim`：数组的轴（维度）数量
2. `ndarray.shape`：数组的维度。一个整数元组，用于指示数组在每个维度上的大小，长度即`ndim`
3. `ndarray.size`：数组的总元素数。等于`shape`元素之积。
4. `ndarray.dtype`：描述数组中元素类型的对象。可以使用标准的 Python 类型创建或指定 dtype。此外，Numpy 还提供自己的类型，例如：numpy.int32
