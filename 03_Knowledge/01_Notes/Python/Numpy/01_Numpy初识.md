# 什么是Numpy

摘自Numpy官方文档：

> NumPy 是 Python 中科学计算的基础包。它是一个 Python 库，提供多维数组对象、各种派生对象（例如掩码数组和矩阵），以及用于对数组进行快速操作的例程集合，包括数学、逻辑、形状操作、排序、选择、I/O、离散傅里叶变换、基本线性代数、基本统计操作、随机模拟等。
# 核心

对于Numpy来说，核心是 `ndarray` 对象，它封装了同类数据类型的 n 维数组。
# Numpy数组和Python列表

需要注意的是，Numpy的数组和标准的Python列表之间有几个区别：

1. Numpy数组在创建时大小固定，这与可以动态增长的Python列表不同。更改 `ndarray` 的大小将创建一个新数组并删除原始数组。
2. Numpy数组中的所有元素都必须是同种数据类型，在内存中占用的大小相同（对象数组除外）。
3. Numpy数组与Python列表相比，执行效率更高，代码量也更少。
# Numpy的功能

对于 Numpy 来说，矢量化 和 广播 是Numpy的两个主要功能，也是其大部分功能的基础。

1. 矢量化：
代码中不存在显式循环或索引，这些操作由后台优化过的、预编译的C代码进行。这说明了矢量化代码更加简洁易读，效率更高，
2. 广播：
广播指操作的隐式逐元素行为，这说明在Numpy中，所有的操作，包括算术运算、逻辑运算、位运算和函数运算等，都已隐式的逐元素方式进行，即它们都会广播。
