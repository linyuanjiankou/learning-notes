> 在[01_变量和print](01_变量和print.md)文章中提到，当赋值给变量的时候，Python会自动判断变量的数据类型，并且简单说明了怎么获取某一个变量的数据类型。本章节将继续这一个话题，列举一些比较常见的数据类型。

数据类型：
- 整数：没有小数的整数，包括正负数和0
```python
my_integer = 10
print("Integer:", my_integer) # Integer: 10
```
- 浮点数：带有小数点的数，表示实数
```python
my_float = 2.50
print("Float:", my_float) # Float: 2.5
```
- 字符串：由零个或多个字符组成的有序序列，用于表示文本
```python
my_string = "hello"
print("String:", my_string) # String: hello
```
- 布尔：存储`TRUE / False`的逻辑数据类型，本质上是整数的子类
```python
my_bool = True
print("Bool:", my_bool) # Bool: True
```
- 集合：一个无序且元素唯一，支持数学集合运算的可变容器
```python
my_set = {7, "Hello", 8.5}
print("Set:", my_set) # Set: {'Hello', 8.5, 7}
```
- 字典：存储可变键值对的容器，一个键对应一个值
```python
my_dictionary = {"name": "Alex", "age": 18}
print("Dicionary:", my_dictionary) # Dicionary: {'name': 'Alex', 'age': 18}
```
- 元组：一个不可变的有序可重复集合
```python
my_tuple = (7, "Hello", 8.5)
print("Tuple:", my_tuple) # Tuple: (7, 'Hello', 8.5)
```
- 范围：不可变的整数序列，常用于循环
```python
my_range = range(5)
print("Range:", my_range) # Range: range(0, 5)
```
- 列表：一个可变的有序序列，支持存入不同数据类型的元素
```python
my_list = [22, "Hello", True, 3.2]
print("List:", my_list) # List: [22, 'Hello', True, 3.2]
```
- None：表示“无值”的空对象，可用于占位等用途
```python
my_none = None
print("None:", my_none) # None: None
```

在[01_变量和print](01_变量和print.md)文章中提过，要想获取变量的数据类型，可以使用`type()`函数：
```python
my_var_1 = 'Hello world'
my_var_2 = 21

print(type(my_var_1)) # <class 'str'>
print(type (my_var_2)) # <class 'int'>
```
在以上提到的数据类型中，在系统的对应关系如下：
- 整数 -> int
- 浮点数 -> float
- 字符串 -> str
- 布尔 -> bool
- 集合 -> set
- 字典 -> dict
- 范围 -> range
- 列表 -> list
- None -> NoneType
除此之外，Python内置的`isinstance()`函数让你可以查看一个变量是否匹配特定的数据类型，它接受一个对象和一个数据类型，然后返回一个和布尔值。例如：
```python
isinstance('Hello world', str) # True
isinstance(42, int) # True
isinstance('John Doe', int) # False
```
