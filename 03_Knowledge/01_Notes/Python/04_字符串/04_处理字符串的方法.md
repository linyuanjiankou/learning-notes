- `upper()`: 返回一个所有字符都转换为大写的新建字符串。
```python
my_str = 'hello world'

uppercase_my_str = my_str.upper()
print(uppercase_my_str)  # HELLO WORLD
```
- `lower()`: 返回一个所有字符都转换为小写的新建字符串。
```python
my_str = 'Hello World'

lowercase_my_str = my_str.lower()
print(lowercase_my_str)  # hello world
```
- `strip()`: 返回一个新建字符串，移除指定的前导和尾随字符或字符串，如果不传入参数，默认移除空白字符（空格、制表符、换行符等）。
```python
my_str_1 = ' hello world '
my_str_2 = 'abchello worldabc'

print(my_str_1.strip()) # hello world
print(my_str_2.strip('abc')) # hello world
```
- `replace(old, new)`: 返回一个新建字符串，其中所有的`old`都被替换为`new`。
```python
my_str = 'hello world'
print(my_str.replace('hello', 'hi')) # hi world
```
- `split(separator)`: 将字符串按照指定的分隔符拆分成字符串列表，如果未指定分隔符，则按照空白字符进行拆分。
```python
my_str = 'hello world'
print(my_str.split()) # ['hello', 'world']
```
- `join(iterable)`: 将可迭代对象（例如列表、元组）的元素用分隔符连接成一个字符串。
```python
sep = "-"
items = ["2025", "05", "10"]
result = sep.join(items)
print(result)   # 2025-05-10
```
- `startswith(prefix)`: 返回一个布尔值，指示字符串是否以指定的前缀开头。
```python
my_str = 'hello world'
print(my_str.startswith('hello')) # True
```
- `endswith(suffix)`: 返回一个布尔值，只是字符串是否以指定的后缀结尾。
```python
my_str = 'hello world'
print(my_str.endswith('world')) # True
```
- `find(substring)`: 返回`substring`第一次出现的索引，如果未找到则返回`-1`。
```python
my_str = 'hello world'
print(my_str.find('world')) # 6
```
- `count(substring)`: 返回子字符串在字符串中出现的次数。
```python
my_str = 'hello world'
print(my_str.count('o')) # 2
```
- `capitalize()`: 返回一个新字符串，首个字符大写，其余字符小写。
```python
my_str = 'hello world'
print(my_str.capitalize()) # Hello world
```
- `isupper()`: 返回一个布尔值，判断字符串中的所有字母是否都是大写。
```python
my_str = 'hello world'
print(my_str.isupper()) # False
```
- `islower()`: 返回一个布尔值，判断字符串中的所有字母是否都是小写。
```python
my_str = 'hello world'
print(my_str.islower()) # True
```
- `title()`: 返回一个新建字符串，其中每一个单词的首字母均大写。
```python
my_str = 'hello world'
print(my_str.title()) # Hello World
```
