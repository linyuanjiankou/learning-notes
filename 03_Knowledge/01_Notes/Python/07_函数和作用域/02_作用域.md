# What is Scope?
在Python中，作用域决定了你可以访问变量的点。它控制变量的生命期以及变量在代码不同部分的解析方式。

为了正确确定作用域，Python遵循 **LEGB** 规则，该规则代表以下内容：

- 局部作用域(L)：在函数或类中定义的变量。
- 封闭作用域(E)：定义在封闭或嵌套函数中的变量。
- 全局作用域(G)：在模块或文件顶层定义的变量。
- 内置作用域(B)：Python中为预定义函数、模块、关键字和对象保留的名称。

# How to use Scope?
## 局部作用域
在函数或类内部声明的变量只能在该函数或类内部访问。

```python
def my_func():
    my_var = 10
    print(my_var)
```

在这种分支中，`my_func`函数有它自己的作用域，外部无法访问该作用域。调用`my_func`会输出 10，但在函数外打印则会导致`NameError`：

```python
def my_func():
    my_var = 10 # Locally scoped to my_func
    print(my_var)

my_func() # 10

print(my_var) # NameError: name 'my_var' is not defined
```

## 封闭作用域
嵌套在另一个函数内部的函数可以访问它所嵌套的函数的变量。

例如：
```python
def outer_func():
    msg = 'Hello there!'

    def inner_func():
        print(msg)

    inner_func()

outer_func() # Hello there!
```

在此示例中，内部函数`inner_func`可以自由访问在外部函数`outer_func`中定义的`msg`变量，然而，请注意外部函数无法访问在任何嵌套函数中定义的变量。我的理解是，函数分级，子函数可以访问父函数中的变量，父函数没有权限访问子函数中的变量。

当然子函数对父函数的不可变变量只有访问权没有更改权，如果想要更改的话可以使用关键字`nonlocal`声明以下变量之后在进行更改操作。

```python
def outer():
    x = 10          # 外层函数的局部变量
    def inner():
        nonlocal x  # 声明 x 来自外层函数
        x = 20      # 修改外层函数的 x
    inner()
    print(x)        # 输出 20，而不是 10
```
## 全局作用域
声明在任何函数或类之外的变量，这些变量在可以在程序的任何地方访问。

```python
my_var = 100

def show_var():
    print(my_var)

show_var() # 100
print(my_var) # 100
```

如果你想让在函数内部定义的局部作用域变量可以全局访问，你可以使用`global`关键字：
```python
my_var_1 = 7

def show_vars():
    global my_var_2
    my_var_2 = 10
    print(my_var_1)
    print(my_var_2)

show_vars() # 7 10

# my_var_2 is now a global variable and can be accessed anywhere in the program
print(my_var_2) # 10
```

## 内置作用域
Python的所有内置函数、模块和关键字，并且在你的程序中的任何地方可用。
