# 一般工作流程
1.  `nano 文件名.c`: 打开/创建文件
2. 直接打字，键盘方向键移动光标
3. `Ctrl + o`保存，按`Enter`确认
4. `Ctrl + x`退出
# 其他快捷键
1. `Alt + 6`: 复制一行，或选中文字后复制
2. `Ctrl + K`: 剪切一行，或选中文字后剪切
3. `Ctrl + U`: 粘贴
4. `Alt + U`: 撤销
5. `Ctrl + W`: 搜索，输入关键词回车
6. `Ctrl + Shift + -`: 跳转到指定行，然后输入行号
7. `Alt + N`: 显示行号，再按一次取消
8. `Ctrl + G`: 帮助文档
9. `Alt + I`: 在当前会话中开启/关闭“自动缩进”
